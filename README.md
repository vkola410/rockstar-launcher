# Rocksted Visual — Script

Скриптовая часть **Rocksted Visual** для Roblox, расширяющая возможности клиента.

При подключении скрипта в Roblox клиент получает дополнительный функционал и становится **Rocksted Client**.

Без скрипта rocksted также может работать, сохраняя базовые возможности.
